# Store listing draft

## Name
UniFeedback Assistant

## Short description
Fill feedback dropdowns using ratings you choose. Review every answer before submitting.

## Full description
UniFeedback Assistant helps students interact with standard feedback forms more efficiently. Scan the currently open page, choose one rating for all detected dropdowns or set ratings individually, and apply your selections. By default, it only fills unanswered boxes.

The extension does not submit forms, collect login details, or send page data to a server. Students remain responsible for reviewing and submitting their own feedback.

## Permission rationale
- activeTab: access the currently active page only after the student invokes the extension.
- scripting: inspect and update standard dropdowns on the active page.
- storage: remember local interface preferences.

## Privacy
No personal data is transmitted or sold. No remote analytics or tracking is included.
